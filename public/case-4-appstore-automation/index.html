    Case 4 — App Store 심사 자동화와 서명 지옥

    배경과 시기GitHub에서 피드백 남기기

    • 3개 앱(Moon Whisper · 내일이없다면 · 내 인생그래프)을 연달아 심사에 올려야 하는 상황.
    • 수동 제출은 앱당 수십 분 + 휴먼 에러 위험.

    마주한 문제GitHub에서 피드백 남기기

    1. ASC 웹 콘솔 없이 프로그램적으로 심사 제출
    2. 버전별 거절 이력 관리와 재제출
    3. iOS 서명(프로비저닝 프로필)과 AAB/JVM 타깃 빌드 실패

    시행착오GitHub에서 피드백 남기기

    • 심사 거절: moon_whisper 1.4.1 REJECTED — 원인 수정 후 재제출 필요
    • 빌드 실패: 2026-08-19 fix(moon_whisper): 플러그인 모듈의 JVM 타깃을 11로 맞춰 AAB 빌드를 되살린다 (refs #410)
    • 서명 실패 연쇄: allow automatic store profile selection → use manual distribution signing in release → align project release signing identity — 자동→수동→정렬로 3번 방향을 바꿔야 했다
    • 다른 앱: if_tomorrow_never_comes INVALID_BINARY, my_life_graph REJECTED — 앱마다 다른 원인

    해결GitHub에서 피드백 남기기

    • ASC iris API 직접 호출로 심사 제출 자동화: 요청·응답 전문 9,100줄을 증거로 보존(asc_official_api.json)
    • 거절 기록 삭제 → 재제출 → WAITING_FOR_REVIEW 전환까지 API로 수행
    • 서명: 수동 distribution signing + identity 정렬로 최종 해결
    • GitHub Actions로 서명된 업로드 자동화: feat(apps): enable signed mobile store uploads (2026-08-19)
