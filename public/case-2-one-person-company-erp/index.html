    접수→인증→분류→제작→전달 상태 머신을 갖춘 웹 시스템 + 어드민 16화면.

      직접 선택

      직접 선택. 이유: 1인 파이프라인은 절차가 계속 바뀌고, 바뀔 때마다 코드로 즉시 반영 가능해야 했다. 기성품은 절차가 제품을 따라가게 만든다.

    2. 어드민 한 번에 완성vs접수→전달 순차 구축

      순차 선택

      순차 선택. 가장 아픈 곳(상태 추적)부터.

    3. 상태를 대화 기록vsDB

      DB 선택

      DB 선택. 대화는 증발하고, DB는 에이전트가 읽는다.
