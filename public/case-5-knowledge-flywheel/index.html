    Case 5 — 지식 플라이휠: 위키가 스스로 도는 구조

    배경과 시기GitHub에서 피드백 남기기

    • 2026-07-16 LLM Wiki 첫 커밋: 3정체성 지식 베이스 — 개발자·투자자·철학자의 기록을 한곳에.
    • 기록이 쌓이는데도 “다시 안 읽게 되는” 노트의 운명이 아쉬웠다.

    마주한 문제GitHub에서 피드백 남기기

    1. 기록이 늘어도 꺼내 쓰지 못함 (검색 불가)
    2. 비공개 지식을 안전하게 공개할 방법 없음
    3. 여러 AI 에이전트가 같은 지식을 못 쓰게 함
    4. 화면(뷰어)이 없어 스스로도 안 봄

    시행착오GitHub에서 피드백 남기기

    • 검색 엔진의 한국어 처리: 조사가 붙은 질의는 실패 — 명사형 보정 로직(refineQuery())과 그 근거를 문서화
    • 패리티 불일치: 로컬 콘솔과 엔진의 검색 결과가 달라 “화면이 거짓말하는” 상황 → 원인은 옛 wiki_id 기본값 → 수정 후 완전일치 3/5, 상위3 4/5로 검증
    • MCP 브릿지 포트 불일치(8425 vs 실제 8424) 발견 → fix(mcp): align wiki MCP bridge port
    • 배포 후 404: CI만 있고 artifact 이동 단계가 없었음 → publish 스크립트 신설로 해소

    해결GitHub에서 피드백 남기기

      • vault → FTS5 검색 엔진(Docker 2컨테이너, 15분 워치독 자동 push, 246페이지)

    • 건강검진 워치독: 매주 링크·frontmatter·길이 자동 점검
