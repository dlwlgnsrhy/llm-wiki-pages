    사례 1 — 기획서.hwp에서 App Store 판매중까지 (22개월)

    문제: 혼자서 기획→백엔드→모바일→심사→배포→재심사까지 전부 해야 했다 (거절 3회 포함). 해결: Flutter 전환 + ASC API 제출 자동화 + 서명 파이프라인 구축. 결과: Moon Whisper App Store 판매중(READY_FOR_SALE), 재제출이 당일 처리되는 체계 확립.

    사례 3 — 멀티에이전트 5부서 제도 설계

    문제: 여러 AI 에이전트가 같은 repo를 두고 충돌했고, 누가 무엇을 했는지 대화 기록으로는 판정이 안 됐다. 해결: AI에게 권한이 아니라 계약을 — 5부서 조직, handoff STATE 머신, 삼중 신호 판정기, 사람 승인 게이트 6종. 결과: 충돌이 8단계로 자동 판정되고, 부서 상태가 파일로 영속화되며, 위험 경계가 명문화된 조직이 됐다 (현재도 운영중).

    사례 4 — App Store 심사 자동화와 서명 지옥

    문제: 3개 앱의 심사 제출이 웹 콘솔 수동 작업이었다 — 느리고, 기록이 안 남고, 반복될수록 실수가 쌓였다. 해결: ASC(iris) API 직접 호출로 제출 자동화 + GitHub Actions 서명 업로드 파이프라인. 결과: 제출 전문 9,100줄이 증거로 남고, 서명 실패 3단계를 커밋으로 극복 — 재제출이 절차가 아닌 명령이 됐다.
