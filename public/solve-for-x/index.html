    무슨 회사인가GitHub에서 피드백 남기기

    어떻게 시작하는가GitHub에서 피드백 남기기

    • 반복되는 업무와 실제 우회 방법을 듣습니다.
    • 작은 범위와 완료 기준을 먼저 합의합니다.
    • 현재의 도구와 데이터 흐름을 존중하면서 필요한 만큼 연결합니다.
    • 자동화할 부분과 사람이 승인할 부분을 나눕니다.
    • 확인 가능한 결과만 전달하고, 확인하지 못한 부분은 남겨 둡니다.
