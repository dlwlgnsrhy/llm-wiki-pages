    마주한 문제GitHub에서 피드백 남기기

    1. 여러 에이전트(Claude·Codex)가 동시에 같은 코드를 고치면 충돌
    2. 누가 무엇을 했는지 대화 기록만으로는 판정 불가
    3. AI의 자동 실행이 위험한 경계(배포·결제·발송)를 넘을 위험

    시행착오GitHub에서 피드백 남기기

    • worktree가 난립하며 어디서 무엇을 했는지 추적 불가 → worktree cleanup baseline → migration verification → consolidation gates로 단계적 정리
    • 대화창의 자기보고는 증거가 안 됨 → “실행 사실” 계층 도입 필요성 학습

    해결GitHub에서 피드백 남기기

    • 5부서 고정: 전략·재무 / 고객·마케팅·성장 / 제품·출시 / 플랫폼·운영 / 지식·프로젝트 관리 — 각 부서에 고정 dept/* 브랜치 + 물리 worktree
    • handoff STATE 머신: IDLE / ACTIVE / BLOCKED / READY_FOR_REVIEW + branch@commit 필수 기록
    • 삼중 신호 판정기: Git 사실 × OS 프로세스(lsof) × handoff 의도를 교차 검증해 CONFLICT / DIRTY_UNCLAIMED / DIVERGED / STALE_HANDOFF 등 8단계 판정 (sfx_department_monitor.py, --self-test 포함)
    • 사람 승인 게이트 6종: 외부 발송·결제·배포·DNS/Secret·스토어 제출·PR 병합은 자동 승인 금지
    • 모델 중립: Claude🟣/Codex🟢 어느 에이전트든 같은 부서 계약으로 교대
